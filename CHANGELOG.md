# Changelog

## 1.0.0

Initial edition: the frozen Wiktionary-derived original plus simple,
teaching and special-character datasets. Includes standard-library custom builders,
complete-set verification, source-page attribution, source identifiers and separate
data/documentation and software licenses.

The original preserves `wiktionary-latin-inputs-v1` exactly. The three other files
are new views of that fixed input set; no new source capture or paradigm expansion
is included.
